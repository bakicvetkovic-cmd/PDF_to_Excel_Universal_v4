PDF to Excel Universal Converter v4

A Windows desktop tool for extracting text from selectable-text PDF files into Excel.

REQUIREMENTS
- Windows 10/11
- Python 3.10 or newer, with the Python launcher (py) available
- PyMuPDF and openpyxl (installed by INSTALL.bat)

QUICK START
1. Extract this ZIP archive to a folder.
2. Install Python 3.10+ from https://www.python.org/ if needed. During setup, enable adding Python to PATH.
3. Double-click INSTALL.bat. It installs dependencies and launches the program.
4. Open a PDF, adjust the red column boundaries and blue Data Start line, then click EXPORT TO EXCEL.

IMPORTANT
This version extracts selectable text from PDFs. It does not perform OCR, so scanned/image-only PDFs require OCR processing before use.
See USER_GUIDE.md for full instructions.
